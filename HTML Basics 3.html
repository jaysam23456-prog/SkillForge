Lesson 3: Your First Web Page

Now it is time to create your first HTML webpage. HTML documents normally contain a head section and a body section.

Basic HTML Structure

A basic HTML document starts with the doctype declaration, followed by the html, head, and body elements.

Your First HTML Code

<!doctype html>
<html>
<head>
    <title>My First Website</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>This is my first webpage.</p>
</body>
</html>
