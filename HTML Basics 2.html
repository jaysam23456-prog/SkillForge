Lesson 2: HTML Elements

HTML elements are the building blocks of a webpage. They tell the browser what each part of the page should be.

Headings

Headings are created using the h1 to h6 elements. The h1 element is normally used for the main heading.

Paragraphs

The p element is used to create paragraphs of text.

Links

The a element is used to create links that allow users to move from one page to another.

Images

The img element allows you to display images on a webpage.
